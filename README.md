# rc-server
The backend socket-server for [Saturn RC](https://github.com/SaturnHosting/rc).

> Disclaimer: This isn't meant to and shouldn't be used to make larger-scale public chat rooms as it really isn't sufficient enough to do so. But feel free to contribute to maybe bring it to that stage!

## Usage
1. Clone this repository
2. Rename `config.json.example` to `config.json`
3. Configure it to your liking with a **secure** token.
4. Run the server with `python server.py` or the docker.

## Features
- Messaging
- Connection messages
- Online player listing.
- Authentication
